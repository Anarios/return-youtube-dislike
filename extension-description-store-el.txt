Το Return YouTube Dislike είναι μια επέκταση ανοιχτού κώδικα η οποία επαναφέρει στο YouTube τον μετρητή dislike.

Τα σχόλια RYD σάς επιτρέπουν να διαβάζετε συζητήσεις και να αντιδράτε σε αυτές κάτω από βίντεο και Shorts όπου τα σχόλια του YouTube είναι απενεργοποιημένα. Τα μέλη Commenter και Premium μπορούν να δημοσιεύουν και να απαντούν, με ειδοποιήσεις για απαντήσεις και likes.

Οι βασικοί μετρητές dislike είναι δωρεάν. Ορισμένες προαιρετικές λειτουργίες έχουν προϋποθέσεις πρόσβασης, μεταξύ των οποίων επί πληρωμή βαθμίδες συνδρομής στο Patreon ή πρόσβαση για επιλέξιμους συντελεστές στο GitHub.

Οι ψήφοι σας βοηθούν στη βελτίωση των εκτιμήσεων. Αποστέλλονται με ένα τυχαίο αναγνωριστικό, το οποίο δημιουργείται την πρώτη φορά που ψηφίζετε ή αντιδράτε σε ένα σχόλιο και δεν συνδέεται με τον λογαριασμό σας Google ή YouTube. Μπορείτε να σταματήσετε την αποστολή ψήφων με την επιλογή «Διακοπή υποβολής like/dislike» στο μενού της επέκτασης.

Εάν δεν λειτουργεί: ανοίξτε την καρτέλα Επεκτάσεις (chrome://extensions/), απενεργοποιήστε αυτήν την επέκταση και ενεργοποιήστε την ξανά. Αυτό θα διορθώσει τα περισσότερα προβλήματα, καθώς υπάρχει ένα σφάλμα στο Chromium που σπάει την επέκταση σε ορισμένες περιπτώσεις. Ας ελπίσουμε ότι η ομάδα του Chromium θα το διορθώσει σύντομα.

Στις 13 Δεκεμβρίου 2021, το YouTube αφαίρεσε απο το API την δυνατότητα να εμφανίζονται τα dislikes.
Η επέκταση αυτή στοχεύει να επαναφέρει αυτή την δυνατότατα στους χρήστες. Ένας συνδυασμός αρχειοθετημένων δεδομένων like και dislike, καθώς και η χρήση των like και dislike των χρηστών της επέκτασης, προβάλουν με τον πιό ακριβή τρόπο την ακροαματικότητα των βίντεο.

Αυτή την στιγμή υπάρχει μια βάση με 200+ εκατομμύρια καταχωρημένα βίντεο και τα likes/dislikes τους, προερχόμενα πριν απο τις 13 Δεκεμβρίου 2021. 

Αναπτύσσεται ενεργά και ενημερώνεται για τις μεταφορτώσεις βίντεο μετά τις 13 Δεκεμβρίου 2021.

Όσο περισσότεροι χρήστες χρησιμοποιούν την επέκταση, τόσο πιο ακριβής θα είναι.

Μη δημοφιλή βίντεο που ανέβηκαν μετά τις 13 Δεκεμβρίου 2021 ενδέχεται να εμφανίζουν λιγότερο ακριβή δεδομένα από τα πιο δημοφιλή βίντεο.

Η επέκταση βρίσκεται επί του παρόντος σε ενεργό φάση ανάπτυξης, επομένως εάν αντιμετωπίζετε προβλήματα, μη διστάσετε να τα αναφέρετε στη σελίδα μας στο GitHub ή στον διακομιστή Discord.
