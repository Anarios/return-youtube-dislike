# Return YouTube Dislike 4.1.2

4.1.2 brings back the 4.1.0 update with fixes. Version 4.1.1 temporarily restored 4.0.6 while we fixed a Firefox problem in 4.1.0.

What's new since 4.0.6:

- Firefox asks for less. Return YouTube Dislike no longer requires any data permission to install or update. Features ask for permission when you turn them on, and you can change them at any time in Add-ons and themes > Return YouTube Dislike > Permissions and data.
- Already on 4.0.6 or 4.1.1? Counts and voting keep working with the permissions you gave before. If you are not signed in, the unused "Personally identifying information" permission is turned off. If you had turned off like/dislike submission, it stays off.
- One step for counts and voting. If dislike counts or vote sharing are off, a small card under the Like and Dislike buttons explains why. Select "Allow in Firefox" to review both in one Firefox prompt, or choose "Don't ask again".
- The "Disable like/dislike submission" switch stays in every browser and stops only your Like and Dislike votes. RYD comment reactions do not depend on it; they work once vote sharing is on.
- If your likes and dislikes aren't counted, the toolbar icon shows a paused state and the menu offers "Count my votes".
- Your random voting ID is created only when you first vote or react, and your own comment reactions are remembered on this device.
- New: RYD comments. Where YouTube comments are turned off, read and react to an RYD discussion. Commenter and Premium members can post and reply, with notifications for replies and likes. You can hide RYD comments in settings.
- No tab opens after an update. The welcome page opens only when you first install.
- You can now allow RYD in private windows. It shows dislike counts only.
- New Hibiscus and custom color themes, a Premium Insights panel you can collapse or hide, and a fix for videos that could freeze the tab.
- New and improved translations.

Fixed since 4.1.0:

- The permission hints under the Like and Dislike buttons could appear see-through on YouTube, and the extension menu could cover Firefox's permission prompt.

Requires Firefox 140 or newer.
