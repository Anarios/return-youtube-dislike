Return YouTube Dislike は、YouTube の「低評価」数を表示する機能を復元する拡張機能です。

RYD コメントでは、YouTube のコメントがオフになっている動画やショート動画で、ディスカッションを閲覧したりリアクションしたりできます。Commenter と Premium のメンバーは投稿や返信ができ、返信や高評価の通知も受け取れます。

基本機能である低評価数の表示は、誰でも無料で利用できます。RYD コメントへの投稿や Premium 動画インサイトなど、一部のオプション機能を利用するには、有料の Patreon メンバーシップ、または対象となる GitHub 貢献者であることが必要です。これらの有料機能の収益は、低評価数を無料で提供し続けるためのサーバー費用に充てられています。15 TB を超えるデータを保管し、1日約2,000万人のユーザーに対応するサーバーを、月数百ドルの予算で運営しています。

あなたの投票は推定値の精度向上に役立ちます。投票はランダムな ID とともに送信されます。この ID は、初めて投票またはコメントへのリアクションを行ったときに作成され、あなたの Google アカウントや YouTube アカウントとは紐づいていません。本拡張機能のメニューにある「高評価/低評価を送信しない」で、投票の送信を停止できます。

動作しない場合：拡張機能ページ（chrome://extensions/）を開き、この拡張機能をいったん無効にしてから、再度有効にしてください。Chromium には特定の状況で拡張機能が動作しなくなるバグがあり、ほとんどの問題はこの手順で解決します。Chromium 開発チームによる早期の修正を期待しています。

2021年12月13日、YouTube は API から低評価数を削除しました。
この拡張機能は、アーカイブされた高評価・低評価のデータと、拡張機能ユーザーによる高評価・低評価を組み合わせてできるだけ正確な評価数を表示し、低評価を見る機能をユーザーの手に取り戻すことを目指しています。

現在、2021年12月13日以前に保存された2億件以上の動画の高評価/低評価数のデータを保有しています。

2021年12月13日以降にアップロードされた動画のデータも継続的に追加し、最新の状態を維持しています。

本拡張機能をより多くのユーザーにご利用いただくことで、精度の高い評価を提供することができます。

2021年12月13日以降にアップロードされたあまり人気のない動画では、人気のある動画に比べて表示されるデータの精度が低くなる可能性があります。

この拡張機能は現在も鋭意開発中であるため、何か問題が発生した場合には、遠慮なく GitHub ページまたは Discord サーバーで報告してください。
