# 安全

### 您是否在跟踪我的观看历史记录？

扩展程序会将当前视频的 ID 以及可获取的点赞数发送给 Return YouTube Dislike API，以便服务器返回并改进点踩数的估算结果。
请求还会向服务器提供公网 IP 地址、请求时间等常规网络元数据。扩展程序不会发送您的 YouTube 帐户名称、YouTube 评论、
YouTube 私密数据或无关网页的内容，也不会在本地另行保存观看历史记录。在 Firefox 中，视频 ID 和点赞数分别获得您的许可后才会发送。

### 如果我不喜欢，你能唯一地识别我吗？

第一次对视频投票或对 RYD 评论作出反应时，扩展程序会生成一个长期使用的随机 ID，以帮助防止滥用。
打开视频和阅读评论时不会发送此 ID。它与 Google 或 YouTube 帐户无关，但 Mozilla 将持久性标识符归类为个人数据。
服务可用它识别来自同一次扩展安装的投票。

### 你到底有什么信息？

查询点踩数的请求会包含视频 ID，以及可获取的点赞数。注册使用随机生成的安装 ID。
提交的投票记录包含该安装 ID、视频 ID、投票选项和投票时间。RYD 评论的反应记录包含同一安装 ID、评论 ID 和你所选的反应。
投票和反应记录还可能包含你使用的扩展程序或用户脚本及其版本，以及点击时的播放位置（如能获取，以整秒计）。
撤回反应后，相应记录会被标记为已移除。你发布的评论和回复会以你的 RYD 昵称公开显示。

### 我的 IP 如何存储？

服务会保存你的 IP 地址。如果请求附有浏览器标识（User-Agent 字符串），服务也会保存这一信息。
这些信息会随已完成的注册、投票、已发布的评论和回复以及对 RYD 评论作出的反应一起保存。
IP 地址用于防止滥用和汇总分析，不会被出售或用于广告。

### 我听到一些关于 OAuth 和访问我的 YouTube 帐户的讨论！

此功能是可选的，并且非常可选择加入。如果您是 YouTube 创作者，并且想与我们分享您的不喜欢统计数据，您可以这样做。 [OAuth](https://en.wikipedia.org/wiki/OAuth#:~:text=but%20without%20giving%20them%20the%20passwords.) 的结构方式实际上非常安全。您可以随时撤销对您帐户的访问权限，并可以向我们授予非常具体的权限。我们不会要求任何不必要的权限。我们只会要求查看您的视频统计数据的权限。

### 我如何信任这个不喜欢计数？

我们已经实施了防止机器人攻击的措施，并将继续努力提高机器人预防系统的有效性：这将帮助我们将不喜欢计数保持为实际计数的良好代表。当然，它永远不会 100% 准确，因此由您决定是否信任计数。

### 您为什么不共享后端代码？

我们会在某个时候共享它 - 但现在真的没有真正的理由共享它。它给人一种虚假的安全感 - 因为在零信任系统中，我们也可以披露一个版本但部署另一个版本。隐藏代码的原因有很多，特别是我们如何对抗垃圾邮件。隐藏/混淆垃圾邮件处理代码是一种相当标准的做法。
