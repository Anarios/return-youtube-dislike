# پرسش‌های متداول

## قبل از مطرح کردن سوال در GitHub یا Discord، لطفاً به این بخش مراجعه کنید.

<br>

### **۱. این افزونه داده‌ها را از کجا دریافت می‌کند؟**

ترکیبی از Google APIها و داده‌های جمع‌آوری‌شده.

ما تمام داده‌های موجود را در دیتابیس خود ذخیره می‌کنیم تا پس از اینکه Google تعداد dislike را در API خود خاموش کرد، در دسترس باشد.

<br>

### **۲. تعداد dislike ویدیو به‌روزرسانی نمی‌شود**

در حال حاضر dislikeهای ویدیو cache می‌شوند و خیلی مکرر به‌روزرسانی نمی‌شوند. هر ۲ الی ۳ روز یک‌بار، نه بیشتر.

بله، ایده‌آل نیست، اما وضعیت فعلی این‌گونه است. در حال کار روی بهبود دفعات به‌روزرسانی آن‌ها هستیم.

<br>

### **۳. این چگونه کار می‌کند؟**

این افزونه video id ویدیویی را که در حال تماشای آن هستید جمع‌آوری می‌کند، dislike (و سایر فیلدها مانند viewها، likeها و غیره) را با استفاده از API ما دریافت می‌کند، اگر این اولین باری است که ویدیو توسط API ما دریافت شده است، از YouTube API برای دریافت داده‌ها استفاده می‌کند، سپس داده‌ها را در یک پایگاه داده برای اهداف caching (حدود ۲ الی ۳ روز cache می‌شود) و بایگانی ذخیره کرده و به شما برمی‌گرداند. سپس افزونه dislikeها را به شما نشان می‌دهد.

<br>

### **۴. پس از توقف بازگرداندن تعداد dislike توسط YouTube API چه اتفاقی خواهد افتاد؟**

بخش backend به استفاده از ترکیبی از آمار dislike آرشیو شده، برآوردهای تخمین‌زده‌شده از داده‌های کاربران افزونه و برآوردهای مبتنی بر نسبت view/like برای ویدیوهایی که dislikeهای آن‌ها آرشیو نشده و برای آرشیوهای قدیمی dislike تغییر وضعیت خواهد داد.

<br>

### **۵. تعداد dislike چگونه محاسبه می‌شود؟**

پروژه RYD از آرای کاربران خود برای تخمین تعداد dislike استفاده می‌کند.

- اگر ویدیو پس از خاموش شدن API آپلود شده باشد:

  $$ \textup{RYD Dislike Count} = \left( \frac{\textup{RYD Users Dislike Count}}{\textup{RYD Users Like Count}} \right) \times \textup{Public Like Count} $$

- اگر دیتابیس RYD به نوعی تعداد واقعی like و dislike را داشته باشد (ارائه‌شده توسط آپلودکننده یا از آرشیو)، تعداد dislike بر اساس هر دو - آرای کاربران و مقدار آرشیو شده محاسبه خواهد شد. مقدار آرشیو شده با گذشت زمان تأثیر کمتری بر شمارش نهایی خواهد داشت.
