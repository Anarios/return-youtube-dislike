# پرسش‌های متداول

### **۱. این افزونه داده‌ها را از کجا دریافت می‌کند؟**

ترکیبی از APIهای Google و داده‌های جمع‌آوری‌شده.

ما تمام داده‌های موجود را در پایگاه داده خود ذخیره می‌کنیم تا پس از توقف ارائه تعداد نپسندها در API شرکت Google، همچنان در دسترس باشند.

<br>

### **۲. تعداد نپسندهای ویدیو به‌روزرسانی نمی‌شود**

در حال حاضر تعداد نپسندهای ویدیو در حافظه نهان ذخیره می‌شود و خیلی مکرر به‌روزرسانی نمی‌شود؛ هر ۲ الی ۳ روز یک‌بار، نه بیشتر.

بله، ایده‌آل نیست، اما وضعیت فعلی این‌گونه است. در حال کار روی بهبود دفعات به‌روزرسانی آن‌ها هستیم.

<br>

### **۳. این چگونه کار می‌کند؟**

این افزونه شناسه ویدیویی را که در حال تماشای آن هستید جمع‌آوری می‌کند و تعداد نپسندها (و سایر اطلاعات مانند تعداد بازدیدها، پسندها و غیره) را از طریق API ما دریافت می‌کند. اگر این اولین بار باشد که API ما اطلاعات آن ویدیو را دریافت می‌کند، از API شرکت YouTube برای دریافت داده‌ها استفاده می‌کند. سپس داده‌ها را برای نگهداری در حافظه نهان (حدود ۲ الی ۳ روز) و بایگانی در یک پایگاه داده ذخیره می‌کند و به شما برمی‌گرداند. در نهایت، افزونه تعداد نپسندها را به شما نشان می‌دهد.

<br>

### **۴. پس از توقف ارائه تعداد نپسندها در API شرکت YouTube چه اتفاقی خواهد افتاد؟**

بخش سرور به استفاده از ترکیبی از آمار بایگانی‌شده نپسندها، برآوردهای استخراج‌شده از داده‌های کاربران افزونه و برآوردهای مبتنی بر نسبت تعداد بازدید به تعداد پسندها تغییر وضعیت خواهد داد. این برآوردهای مبتنی بر نسبت برای ویدیوهایی به کار می‌روند که آمار نپسندهای آن‌ها بایگانی نشده است یا بایگانی قدیمی دارند.

<br>

### **۵. تعداد نپسندها چگونه محاسبه می‌شود؟**

پروژه RYD از آرای کاربران خود برای تخمین تعداد نپسندها استفاده می‌کند.

- اگر ویدیو پس از خاموش شدن API آپلود شده باشد:

$$
D_{\mathrm{RYD}} = \left( \frac{D_u}{L_u} \right) \times L_p
$$

در این فرمول، $D_{\mathrm{RYD}}$ تعداد نپسندهای تخمینی RYD، $D_u$ تعداد نپسندهای کاربران RYD، $L_u$ تعداد پسندهای کاربران RYD و $L_p$ تعداد پسندهای قابل مشاهده برای عموم است.

- اگر پایگاه داده RYD به نوعی تعداد واقعی پسندها و نپسندها را داشته باشد (ارائه‌شده توسط بارگذار یا از بایگانی)، تعداد نپسندها بر اساس هر دو منبع، یعنی آرای کاربران و مقدار بایگانی‌شده، محاسبه خواهد شد. مقدار بایگانی‌شده با گذشت زمان تأثیر کمتری بر شمارش نهایی خواهد داشت.
