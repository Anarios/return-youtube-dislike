# Частыя пытанні

## Перш чым задаваць пытанне на GitHub або ў Discord, калі ласка, азнаёмцеся з гэтым раздзелам.

<br>

### **1. Адкуль гэтае пашырэнне бярэ дадзеныя?**

Камбінацыя Google API і сабраных дадзеных (скрэйпінгу).

Мы захоўваем усе даступныя дадзеныя ў нашай базе, каб яны заставаліся даступнымі пасля таго, як Google адключыць лічыльнік непадабаек у сваім API.

<br>

### **2. Колькасць непадабаек у відэа не абнаўляецца**

Зараз непадабайкі для відэа кэшуюцца і абнаўляюцца не вельмі часта. Прыкладна раз на 2–3 дні, не часцей.

Так, гэта не ідэальна, але як ёсць. Мы працуем над тым, каб павялічыць частату абнаўленняў.

<br>

### **3. Як гэта працуе?**

Пашырэнне збірае ідэнтыфікатар відэа (video id), якое вы глядзіце, і запытвае колькасць непадабаек (а таксама іншыя палі: прагляды, падабайкі і г. д.) праз наш API. Калі гэта першы запыт відэа ў нашым API, наш API выкарыстоўвае YouTube API для атрымання дадзеных, пасля чаго захоўвае іх у базе для кэшавання (кэш захоўваецца каля 2–3 дзён) і архівавання, і вяртае іх вам. Затым пашырэнне адлюстроўвае непадабайкі на старонцы.

<br>

### **4. Што адбудзецца пасля таго, як YouTube API спыніць вяртаць колькасць непадабаек?**

Сервер пераключыцца на выкарыстанне камбінацыі архіўных статыстычных дадзеных аб непадабайках, ацэнак, экстрапаляваных на аснове паводзін карыстальнікаў пашырэння, і ацэнак на аснове суадносін праглядаў і падабаек для відэа, непадабайкі якіх не былі заархіваваныя або чые архіўныя дадзеныя састарэлі.

<br>

### **5. Як разлічваецца колькасць непадабаек?**

RYD выкарыстоўвае галасы сваіх карыстальнікаў для экстрапаляцыі колькасці непадабаек.

- Калі відэа было загружана пасля адключэння API:

  $$ \textup{RYD Dislike Count} = \left( \frac{\textup{RYD Users Dislike Count}}{\textup{RYD Users Like Count}} \right) \times \textup{Public Like Count} $$

- Калі ў базе дадзеных RYD нейкім чынам захавалася фактычная колькасць падабаек і непадабаек (прадастаўленая аўтарам або з архіва), колькасць непадабаек будзе разлічвацца на аснове абодвух паказчыкаў: галасоў карыстальнікаў і архіўнага значэння. З часам архіўнае значэнне будзе аказваць усё меншы ўплыў на выніковы лік.
