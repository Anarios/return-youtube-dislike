# امنیت

### آیا تاریخچه تماشای من را ردیابی می‌کنید؟

این افزونه ID ویدیوی فعلی و در صورت در دسترس بودن، تعداد like قابل مشاهده آن را به Return YouTube Dislike API ارسال می‌کند زیرا سرور برای بازگرداندن و بهبود تخمین dislike به آن‌ها نیاز دارد. این درخواست همچنین متادیتای استاندارد شبکه مانند آدرس IP عمومی و زمان درخواست را ارسال می‌کند. این افزونه نام حساب YouTube شما، نظرات، داده‌های خصوصی YouTube یا محتوای صفحات غیرمرتبط را ارسال نمی‌کند و فهرست سابقه تماشای محلی جداگانه‌ای نگهداری نمی‌کند.

### آیا در صورت ثبت dislike می‌توانید من را به طور منحصربه‌فرد شناسایی کنید؟

این افزونه یک شناسه تصادفی پایدار برای ارسال رای مقاوم در برابر سوءاستفاده ایجاد می‌کند. این شناسه از حساب Google یا YouTube شما مشتق نشده و به آن متصل نیست، اما Mozilla شناسه‌های پایدار را به عنوان داده‌های شخصی طبقه‌بندی می‌کند. این شناسه به سرویس اجازه می‌دهد تا آرای ارسالی را با همان نصب افزونه مرتبط کند.

### دقیقاً چه اطلاعاتی دارید؟

برای درخواست‌های تعداد dislike: شناسه ویدیوی فعلی و در صورت در دسترس بودن، تعداد like قابل مشاهده. برای ثبت‌نام و ارسال رای: شناسه تصادفی کاربر افزونه، شناسه ویدیو، رای انتخاب‌شده و برچسب زمانی. این API همچنین آدرس IP شما را دریافت می‌کند. آدرس‌های خام در RAM باقی می‌مانند و هش‌ها برای کنترل سوءاستفاده ذخیره می‌شوند. ویژگی‌های اختیاری پریمیوم از شناسه حساب، نام، آدرس ایمیل، تصویر پروفایل، اطلاعات عضویت و توکن سشن سرویس بازگردانده شده توسط ورود با Patreon یا GitHub که توسط کاربر آغاز شده است، استفاده می‌کنند. برای نسخه 4.0.6 و نسخه backend متناظر با آن، دسترسی Patreon از روی شناسه‌های سطوح دارای حق فعلی تعیین می‌شود، نه اطلاعات مالی.

### آدرس IP من چگونه ذخیره می‌شود؟

آدرس‌های خام IP در RAM باقی می‌مانند و هش‌ها ذخیره می‌شوند. این اطلاعات برای جلوگیری از سوءاستفاده و تحلیل‌های آماری کلی استفاده می‌شود. فروخته نمی‌شود و برای تبلیغات استفاده نمی‌گردد.

### من گفتگوهایی درباره OAuth و دسترسی به حساب YouTube خود شنیده‌ام!

ورود به بخش تحلیلی پریمیوم اختیاری است و فقط پس از اینکه کاربر ورود به Patreon یا GitHub را در افزونه انتخاب کند آغاز می‌شود. فرآیند OAuth جزئیات حساب و یک توکن سشن Return YouTube Dislike را برمی‌گرداند که برای احراز هویت درخواست‌های API پریمیوم استفاده می‌شود. در نسخه 4.0.6 و نسخه متناظر backend آن، واجد شرایط بودن در Patreon از شناسه‌های سطح‌های دارای حق فعلی استفاده می‌کند؛ این سرویس مبالغ عضویت، تاریخ‌ها یا وضعیت شارژ، پرداخت‌های مادام‌العمر یا وضعیت حامی را درخواست یا استفاده نمی‌کند. Firefox قبل از شروع تبادل داده‌های حساب، رضایت جداگانه‌ای برای داده‌های احراز هویت درخواست می‌کند. خروج از حساب، جزئیات حساب ذخیره‌شده و سشن را از افزونه پاک می‌کند. لغو مجوز داده‌های احراز هویت در Firefox نیز سشن حساب را پاک می‌کند و تبادل داده‌های بعدی حساب را تا زمانی که دوباره رضایت داده و وارد شوید مسدود می‌سازد. در صورت فعال بودن Browser sync، شناسه نصب، تنظیمات و سشن حساب ممکن است همگام‌سازی شوند.

### چگونه می‌توانم به این تعداد dislike اعتماد کنم؟

ما اقداماتی را برای جلوگیری از حملات بات‌ها اجرا کرده‌ایم و به کار روی بهبود اثربخشی سیستم جلوگیری از بات ادامه خواهیم داد: این به ما کمک می‌کند تا تعداد dislike را به عنوان نماینده خوبی از تعداد واقعی حفظ کنیم. البته هرگز ۱۰۰٪ دقیق نخواهد بود، بنابراین تصمیم‌گیری در مورد اینکه به این تعداد اعتماد کنید یا نه بر عهده شماست.

### چرا کد backend را به اشتراک نمی‌گذارید؟

ما در نقطه‌ای آن را به اشتراک خواهیم گذاشت - اما در حال حاضر واقعاً دلیل موجهی برای به اشتراک گذاشتن آن وجود ندارد. این یک حس کاذب از امنیت ایجاد می‌کند - زیرا در یک سیستم zero-trust، ما می‌توانستیم یک نسخه را اعلام کنیم اما نسخه دیگری را مستقر نماییم. دلایل متعددی برای پنهان نگه داشتن کد وجود دارد، به ویژه نحوه مبارزه ما با هرزنامه. پنهان‌سازی/مبهم‌سازی کد رسیدگی به هرزنامه یک روش کاملاً استاندارد است.
