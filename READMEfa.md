# Return YouTube Dislike

<p align="center">
    <b>Return YouTube Dislike یک افزونه متن‌باز است که تعداد نپسندهای YouTube را بازمی‌گرداند.</b><br>
    برای Chrome و Firefox به صورت افزونه مرورگر در دسترس است.<br>
    همچنین برای سایر مرورگرها به صورت اسکریپت کاربر جاوااسکریپت در دسترس است.<br><br>
    <img width="400px" src="https://user-images.githubusercontent.com/18729296/141743755-2be73297-250e-4cd1-ac93-8978c5a39d10.png"/>
</p>

## داستان ماجرا

در ۱۰ نوامبر ۲۰۲۱، Google [اعلام کرد](https://blog.youtube/news-and-events/update-to-youtube/) که تعداد نپسندهای YouTube حذف خواهد شد.

علاوه بر این، فیلد `dislike` در YouTube API در تاریخ ۱۳ دسامبر ۲۰۲۱ [حذف شد](https://support.google.com/youtube/thread/134791097/update-to-youtube-dislike-counts)، که هرگونه امکان قضاوت درباره کیفیت محتوا قبل از تماشا را از بین برد.

## عملکرد

با حذف آمار نپسندها از API شرکت YouTube، بخش سرور ما به استفاده از ترکیبی از آمار نپسندهای جمع‌آوری‌شده و برآوردهای استخراج‌شده از داده‌های کاربران افزونه تغییر یافت.

[پرسش‌های متداول](https://github.com/Anarios/return-youtube-dislike/blob/main/Docs/FAQfa.md)

## چرا اهمیت دارد

می‌توانید در وب‌سایت ما اطلاعات بیشتری کسب کنید: [returnyoutubedislike.com](https://www.returnyoutubedislike.com/)

## مستندات API

استفاده شخص ثالث از این API عمومی با محدودیت‌های زیر مجاز است:

- **ارجاع**: این پروژه باید به طور واضح با لینکی به [returnyoutubedislike.com](https://returnyoutubedislike.com/) ارجاع داده شود.
- **محدودیت نرخ**: محدودیت‌های نرخ برای هر کلاینت ۱۰۰ در دقیقه و ۱۰,۰۰۰ در روز اعمال شده است. این یک کد وضعیت _429_ برمی‌گرداند که نشان می‌دهد برنامه شما باید متوقف شود یا درخواست‌ها را کاهش دهد.

این API از طریق URL پایه زیر در دسترس است:
https://returnyoutubedislikeapi.com

فهرست نقاط پایانی موجود در اینجا در دسترس است:
https://returnyoutubedislikeapi.com/swagger/index.html

### دریافت آرا

مثال برای دریافت آرای یک ویدیو در YouTube با شناسه مشخص:
`/votes?videoId=kxOuG8jMIgI`

```json
{
  "id": "kxOuG8jMIgI",
  "dateCreated": "2022-04-09T21:44:20.5103Z",
  "likes": 31885,
  "rawDislikes": 31946,
  "rawLikes": 457,
  "dislikes": 579721,
  "rating": 1.2085329444119253,
  "viewCount": 3762293,
  "deleted": false
}
```

شناسه ناموجود ویدیو در YouTube، کد وضعیت _404_ "Not Found" (یافت نشد) برمی‌گرداند.

شناسه ویدیو در YouTube با قالب نادرست، کد وضعیت _400_ "Bad Request" (درخواست نامعتبر) برمی‌گرداند.
