# STORE

**Гэты каталог не з'яўляецца абавязковым, вы можаце выдаліць яго, калі не плануеце яго выкарыстоўваць.**

Гэты каталог змяшчае файлы сховішча Vuex Store.
Падтрымка Vuex Store рэалізавана ў фрэймворку Nuxt.js.

Стварэнне файла ў гэтым каталогу аўтаматычна актывуе адпаведную опцыю ў фрэймворку.

Больш падрабязную інфармацыю аб выкарыстанні гэтага каталога глядзіце ў [дакументацыі](https://nuxtjs.org/guide/vuex-store).
