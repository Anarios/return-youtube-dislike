Return YouTube Dislike mengembalikan kemampuan untuk melihat jumlah dislike di Youtube.

Komentar RYD memungkinkan kamu membaca dan bereaksi terhadap diskusi di video dan Shorts yang komentar YouTube-nya dinonaktifkan. Anggota Commenter dan Premium dapat mengirim komentar dan balasan, dengan notifikasi untuk balasan dan like.

Jumlah dislike sebagai fitur inti tersedia gratis untuk semua orang. Beberapa fitur opsional, seperti mengirim komentar RYD dan analitik video Premium, memerlukan keanggotaan Patreon berbayar atau akses untuk kontributor GitHub yang memenuhi syarat. Fitur berbayar ini membantu membiayai server yang membuat jumlah dislike tetap gratis: lebih dari 15 TB data dan sekitar 20 juta pengguna per hari, dengan anggaran beberapa ratus dolar per bulan.

Suara kamu membantu menyempurnakan perkiraan. Suara dikirim dengan ID acak yang dibuat saat pertama kali kamu memberi suara atau bereaksi terhadap komentar, dan ID ini tidak terhubung dengan akun Google atau YouTube kamu. Kamu dapat berhenti mengirim suara dengan “Matikan pengiriman like/dislike” di menu extension.

Jika ini tidak bekerja: buka tab Extension (chrome://extensions/), matikan lalu hidupkan lagi extension ini. Ini biasanya memperbaiki banyak masalah, ini terjadi karena terdapat bug pada Chromium yang dapat merusak extension pada kasus tertentu. Semoga tim Chromium akan segera memperbaikinya.

Mulai 13 Desember 2021, Youtube menghapus kemampuan untuk melihat jumlah dislike dari API mereka.
Extension ini bertujuan untuk mengembalikan kemampuan itu ke pengguna dengan menggunakan kombinasi data arsip like dan dislike, serta data like dan dislike dari pengguna extension untuk menunjukkan jumlah yang lebih akurat.

Sekarang terdapat 200+ juta data like/dislike video yang tersimpan sebelum 13 Desember 2021

Tumbuh secara aktif dan mengikuti perkembangan terbaru pada upload setelah 13 Desember 2021

Semakin banyak pengguna menggunakan extension ini, semakin akurat datanya.

Video yang tidak populer yang diupload setelah 13 Desember 2021 mungkin memiliki data yang kurang akurat dibandingkan dengan video yang populer.

Extension ini sedang aktif dikembangkan, jadi jika kamu mengalami masalah, jangan malu untuk melaporkannya pada halaman GitHub atau server Discord kami.

Lebih banyak fitur akan segera hadir!
