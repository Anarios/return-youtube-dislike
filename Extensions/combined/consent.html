Enable dislike counts in Firefox

RYD needs permission to send the YouTube video ID and available like count to load dislike counts. When you vote, it also sends your choice with a saved random ID.

Firefox will ask you to approve these data permissions. YouTube's own buttons still work if you decline.

What do Firefox's permission labels mean?

Firefox groups extension data into broad categories. Here is what RYD uses:

Personally identifying information
A random voting ID saved by the extension and reused when you submit votes or react to RYD discussion comments. Voting does not use your YouTube email, username, or account ID.
Browsing activity
The YouTube video ID needed to request counts, load RYD discussions, or show analytics for that video.
Website content
The video's visible like count, when available. If you post in RYD Discussions, RYD also receives the comment text and display name you choose to submit.
Website activity
Your like, dislike, or removed vote. If you use RYD Discussions, RYD also receives your reactions and actions such as editing or reporting comments.

Signing in is optional

If you choose GitHub or Patreon sign-in, Firefox asks separately for Authentication information. This covers the authorization and session data used for account features. You do not need GitHub or Patreon sign-in to see counts or submit video votes.

You can change these permissions later in Firefox's extension settings.
